# ads

Finished videos and covers for reels Ric boosts on Instagram. They sit here only so
Instagram can fetch them from a public address when a reel is published through the
API (the same way the daily posts are). Nothing in this folder triggers a workflow.

The source of each video is the launch kit in the app repo
(`chasten-bible-app/Claude outputs/Chasten launch kit`), which also holds the post text.

- `2026-11-10/`: the Friend, Ask and Study reels (kits 28, 27, 29).
